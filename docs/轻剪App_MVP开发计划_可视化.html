「轻剪」拍剪一体 App · MVP 开发计划

打开相机即拍 · 拍完即剪 · 剪完即存 —— 相机（Camera Kit）+ 视频处理（ffmpeg NAPI）闭环工具
HarmonyOS NEXT · API 18+ ArkTS / ArkUI NAPI 7 天 MVP 真机开发
※ 计划示意（v1.0，2026-09-14），详细内容见《轻剪App_MVP开发计划.md》
① MVP 功能范围（4 大模块）

M1 相机拍摄

  • 预览取景（XComponent）
  • 录像 / 拍照
  • 前后摄切换 · 闪光灯
  • 录像 60s 上限
✓ 能录像并落入系统相册

M2 相册导入

  • 系统相册视频网格
  • 单选 / 多选
  • 安全相册选择器（免权限）
✓ 可选任意已有视频

M3 视频编辑

  • 裁剪：起止时间滑块（≥1s）
  • 拼接：多段 + 顺序调整
  • 播放器预览
✓ 裁剪/拼接结果与设定一致

M4 导出

  • 480p / 720p / 1080p 预设
  • 码率选择 · 进度条
  • 保存相册 · 失败提示
✓ 导出视频可播放
